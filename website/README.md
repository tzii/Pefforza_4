# Pefforza website

A static project showcase for Pefforza, published on **[GitHub Pages](https://tzii.github.io/Pefforza_4/)**. The React/Vinext site leads with the Python project's architecture and ways to run it, followed by an independent browser Connect Four demo.

## Run

Requires Node.js 22.13 or later.

```sh
cd website
npm ci
npm run dev
```

## Validate and build

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

The build exports public assets into `dist/client/`. `npm start` serves that output locally. No Python server, credentials, camera, audio permissions, or external API is needed by the website. Fonts and images are served locally.

## GitHub Pages

```sh
npm run build:pages
```

This builds for `/Pefforza_4/` and verifies exported image, font, script, and worker paths, public metadata, section order, and the compiled AI worker. The ordinary `npm run build` continues to support hosting at `/`. Use `PAGES_BASE_PATH` and `PAGES_SITE_URL` to override the Pages location before running `build:pages`.

The repository's [Project website workflow](../.github/workflows/pages.yml) validates pull requests and publishes updates from `main`. Select **GitHub Actions** under repository **Settings → Pages → Build and deployment** for initial setup. You can also launch the workflow manually. Only `dist/client/` is uploaded; the Python application stays in the repository. See [GitHub's custom workflow documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Browser game

The demo uses an independent, bounded JavaScript opponent: random at Easy, a tactical heuristic at Medium, and a depth-five alpha-beta search at Hard. Search runs in a disposable Web Worker with cancellation and an error/retry state. This is **not** the full Python bitboard engine, exact solver, or PPO checkpoint. Those remain available through the project’s documented interfaces.

`lib/geometry.json` is generated from `pefforza/constants.py`; do not edit it manually. Regenerate geometry and Python reference cases from the repository root after installing the package:

```sh
python scripts/export_web_game.py
```

The tests compare browser behavior against 2,377 positions generated by `pefforza.rules`, cover all winning windows, gravity, illegal moves, tactical play, full games, turn locking, and reset/retry behavior. The Python runtime dependencies are unchanged.

## Motion and accessibility

GSAP sequences the hero, pinned horizontal desktop chapters, section entrances, and footer. On smaller screens, the chapters become a natural vertical story. The motion control disables animation and pinning; the site also respects the operating system’s reduced-motion preference. The page remains readable without animation. Game columns support keyboard activation and number keys 1–7 when a column is focused. Native buttons, focus indicators, live game status, and the supplied Base UI tabs/select are used throughout.

The optional proposed `document.modelContext` integration exposes `read_pefforza_game` and `play_pefforza_column`, using the same game state and actions. Unsupported browsers simply use the normal interface. A supported WebMCP runtime was not available for integration verification.
